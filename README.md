## Featured Projects

### [Synsorempire](https://github.com/JoeBuildsThings/synsorempire)

Online store for a fashion shop. Customers browse by category and order on WhatsApp, and the owner manages every product from a private admin area.

* Authentication and row level security on the database
* Product photos stored and resized for each screen through a CDN
* Type check runs on every push through GitHub Actions
* Stack: Next.js, React, Tailwind CSS, Supabase, Cloudinary, Vercel

[Live site](https://synsorempire.vercel.app) | [Source](https://github.com/JoeBuildsThings/synsorempire)

### [JOEBOT](https://github.com/JoeBuildsThings/joebot)

Terminal AI agent built on real tool calling, not a chat wrapper. In active development.

* Reads files, searches code, runs shell commands and searches the live web
* Asks for approval before it writes a file or runs a command, with destructive patterns blocked and file access sandboxed
* Routes across several AI providers and falls back automatically when one runs out of quota
* Keeps personal memory that you can add to and clear

### [GameDeck](https://github.com/JoeBuildsThings/gamedeck)

Rootless in game performance overlay and optimizer for Android 10 to 14.

* Floating HUD with live FPS, frame times, CPU load, RAM and battery thermals
* Reversible gaming profiles with a one tap restore
* Uses Shizuku for privileged actions without root, and hard blocks system packages from ever being touched

### [CGPA Calculator](https://github.com/JoeBuildsThings/cgpa-calculator)

GPA tool built for UNIOSUN's 5.0 grading scale instead of the generic 4.0.

* Multi semester tracking with a running CGPA
* Saves locally so nothing resets on reload
